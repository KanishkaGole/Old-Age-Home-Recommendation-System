# ElderCare Finder — Old Age Home Recommendation System

A practical prototype using the supplied `All_India_Old_Age_Homes.xlsx` workbook. It includes model building, an interactive Streamlit interface, user rating capture, and preliminary feedback evaluation.

## 1. Project structure

```text
old_age_home_recommender/
├── app.py
├── train_model.py
├── evaluate.py
├── requirements.txt
├── data/
│   └── All_India_Old_Age_Homes.xlsx
├── artifacts/
│   ├── content_model.joblib       # generated by training
│   └── homes_cleaned.csv          # generated by training
└── src/
    └── recommender.py
```

## 2. Setup (Windows PowerShell)

```powershell
cd old_age_home_recommender
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

If the dataset is elsewhere, use:

```powershell
python train_model.py --input "D:\path\to\All_India_Old_Age_Homes.xlsx"
```

## 3. Model design

- **Candidate generation:** hard filters for state, district, facility category, care type, gender eligibility, and management type.
- **Ranking:** TF-IDF vectorization over home name, location, address, facility type, care type, gender, management, and remarks; cosine similarity ranks text matches.
- **Contact completeness:** an optional small ranking bonus favors records with phone/email/address fields.
- **No collaborative filtering yet:** the source workbook contains no reliable user-item interaction history.
- **No price-based affordability model:** the source has broad facility categories such as `Free` and `Free, Pay & Stay`, not verified monthly prices.
- **No live vacancy/medical-service guarantees:** verify details directly with each institution.

The ranking score is a relative ranking signal, **not a probability, quality rating, or guarantee of suitability**.

## 4. Rate and collect feedback

1. Open the Streamlit app and set preferences.
2. Browse the recommendations.
3. Expand **Rate this recommendation** on a result and submit a rating from 1 to 5.
4. Ratings are appended to `data/user_ratings.csv`.

Avoid entering sensitive personal or medical details in the optional notes field.

## 5. Evaluate

After collecting ratings, run:

```powershell
python evaluate.py --k 5
```

The report is saved to `artifacts/evaluation_report.csv`. Ratings of 4–5 are treated as relevant, 1–2 as not relevant, and 3 as neutral. Metrics are preliminary because the prototype does not yet record a complete ranked exposure log or obtain representative judgments for all candidates.

For rigorous Precision@K / Recall@K / NDCG evaluation, create a test set where a care professional or study participant judges the relevance of a set of candidate homes for each preference query, then compare model ranking against those judgments.

## 6. Important limitations and ethical safeguards

- This workbook is a directory, not a verified real-time inventory.
- Missing values remain missing; zero/missing bed capacity is flagged for confirmation.
- Cost, current vacancy, nursing availability, accessibility, dementia care, inspection status, and service quality are not sufficiently represented to use as verified filters.
- A text query such as “dementia care” may match words in the text, but does **not** establish that a home provides dementia care.
- Always contact the home to verify current eligibility, fees, services, vacancies, and suitability.
